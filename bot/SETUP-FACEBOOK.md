# חיבור הדף העסקי ל-API

מדריך צעד־צעד לחיבור הדף **מתנות לכל גיל** למערכת. לוקח כשעה, עולה 0 ₪.

> הממשקים של Meta משתנים מדי כמה חודשים, אז התיאור כאן הוא לפי **מה שעושים**
> ולא לפי המיקום המדויק של הכפתורים. אם משהו זז — חפשו לפי השם.

---

## שלב 1 · יצירת אפליקציה (כ-20 דקות)

1. להיכנס ל-<https://developers.facebook.com> ולהתחבר עם החשבון שמנהל את הדף.
2. בתפריט העליון: **My Apps** ← **Create App**.
3. בשאלה על מטרת השימוש לבחור **Other**, ובסוג האפליקציה לבחור **Business**.
4. למלא שם לאפליקציה (למשל `מתנות לכל גיל — בוט`), מייל ליצירת קשר,
   ולשייך לחשבון עסקי (Business portfolio). אם אין — ליצור אחד בחינם.
5. אחרי היצירה: **App settings ← Basic**. שם נמצאים **App ID** ו-**App Secret**
   (צריך ללחוץ Show). שמרו את שניהם בצד — הם נחוצים בשלב 3.

---

## שלב 2 · טוקן ראשוני (כ-10 דקות)

1. להיכנס ל-**Tools ← Graph API Explorer**
   (<https://developers.facebook.com/tools/explorer>).
2. בצד ימין למעלה לבחור את האפליקציה שיצרתם.
3. בשדה **User or Page** לבחור **Get User Access Token**.
4. להוסיף את ההרשאות הבאות (יש שדה חיפוש):

   | הרשאה | למה |
   |---|---|
   | `pages_show_list` | לראות את הדפים שלכם |
   | `pages_read_engagement` | לקרוא תגובות על הפוסטים |
   | `pages_manage_posts` | לפרסם בדף |
   | `pages_manage_engagement` | להגיב לתגובות |

5. ללחוץ **Generate Access Token**, לאשר בחלון שנפתח, ולסמן את הדף
   **מתנות לכל גיל**.
6. להעתיק את הטוקן שהתקבל. **הוא בתוקף לשעה בלבד** — בשלב הבא הופכים אותו לקבוע.

---

## שלב 3 · טוקן קבוע (כ-5 דקות)

שתי פקודות בטרמינל. להחליף את מה שבסוגריים המסולסלים.

**א. הארכת הטוקן ל-60 יום:**

```bash
curl -s "https://graph.facebook.com/v25.0/oauth/access_token?grant_type=fb_exchange_token&client_id={APP_ID}&client_secret={APP_SECRET}&fb_exchange_token={הטוקן_משלב_2}"
```

מהתשובה להעתיק את הערך של `access_token`.

**ב. קבלת טוקן הדף, שלא פג:**

```bash
curl -s "https://graph.facebook.com/v25.0/me/accounts?access_token={הטוקן_הארוך_מסעיף_א}"
```

בתשובה יופיע הדף שלכם עם שני שדות שצריך: **`id`** ו-**`access_token`**.
טוקן הדף הזה לא פג כל עוד לא מחליפים סיסמה ולא מוחקים את האפליקציה.

---

## שלב 4 · חיבור למערכת (דקה)

לפתוח את הקובץ `bot/.env` ולמלא:

```
FB_PAGE_ID=מה שהופיע בשדה id
FB_PAGE_TOKEN=מה שהופיע בשדה access_token של הדף
FB_API_VERSION=v25.0

FB_APP_ID=ה-App ID משלב 1
FB_APP_SECRET=ה-App Secret משלב 1
```

ואז לבדוק:

```bash
python check_facebook.py
```

אם מופיע שם הדף ומספר העוקבים — החיבור עובד.

> **הטוקן הוא סיסמה.** הוא יושב רק בקובץ `.env` על המחשב שלכם, מוחרג מגיט,
> ואין שום סיבה לשלוח אותו במייל, בצ'אט או לאף אחד. מי שמחזיק בו יכול לפרסם
> בדף שלכם.

---

## שלב 5 · הודעות בפרטי (ימים עד שבועות)

כל מה שלמעלה עובד מיד, גם כשהאפליקציה במצב Development. **חוץ מדבר אחד:**
שליחת הודעה פרטית ללקוח אמיתי דורשת את ההרשאה `pages_messaging`, ואותה Meta
מאשרת רק אחרי:

1. **אימות עסקי** — העלאת מסמך עוסק מורשה או ח.פ והוכחת כתובת, ב-Business
   Settings ← Security Center. האימות עצמו לוקח כמה ימי עסקים.
2. **App Review** — הגשת בקשה עם תיאור השימוש וסרטון מסך שמדגים את הזרימה.
   ביקורת אנושית, בדרך כלל מספר ימים.

עד שזה עובר, הבוט יוכל לשלוח בפרטי רק לחשבונות שיש להם תפקיד באפליקציה —
כלומר אליכם. מספיק לבדיקות.
