# מנוע התגובות · מתנות לכל גיל

> **ממשיכים מסשן אחר?** קראו קודם את **[HANDOFF.md](HANDOFF.md)** — מה בנוי, מה הוחלט, מה אסור להפר ומה נשאר.

מערכת מקומית שקוראת פוסט מקבוצת פייסבוק, מבינה מה האדם מחפש, בוחרת מוצר ותמונה,
ומנסחת **תגובה ציבורית** ו**הודעת פתיחה לפרטי** — הכול ממתין לאישור שלכם.
שום דבר לא מתפרסם לבד, ושום נתון לא יוצא מהמחשב שלכם.

---

## התקנה

צריך Python 3.11 ומעלה. **על ווינדוס — ראו [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).**

```bash
cd bot
python3 -m venv venv
source venv/bin/activate          # בווינדוס:  venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # ואז לפתוח את .env ולהדביק את מפתח Claude
python seed.py                    # יוצר שלדים למוצרי החגים עם תאריכי העונה
python run.py
```

אחרי ההפעלה הראשונה: במסך **הגדרות** ממלאים מה העסק עושה במשפט אחד (זה נכנס
לפרומפט), ובמסך **מוצרים** ממלאים את המוצרים ומעלים תמונות. עד שמוצר מסומן
כפעיל — הבוט לא יציע אותו.

ואז לפתוח בדפדפן: <http://127.0.0.1:5000>

בלי מפתח Claude בקובץ `.env` המערכת עדיין עובדת, אבל הניסוחים יהיו תבניתיים
ולא אמיתיים — טוב כדי להתרשם מהמסכים, לא כדי לעבוד.

## המסכים

| מסך | מה עושים בו |
|---|---|
| **תור אישורים** | מדביקים פוסט מקבוצה ומקבלים ניסוח. כאן מאשרים, עורכים או דוחים. |
| **פוסטים** | הבוט מנסח פוסטים לדף לפי מוצר וזווית. מאשרים, קובעים מתי, והם מתפרסמים. |
| **מוצרים** | שם, תיאור, מחירים, מילות מפתח, חלון עונה ותמונות. מה שלא כאן — הבוט לא מזכיר. |
| **הגדרות** | זהות העסק, תקרה יומית, זמן המתנה בין פניות, סף ביטחון, החרגות, עצירת חירום ודוגמאות טון. |
| **היסטוריה** | כל מה שקרה, כולל מה נחסם ולמה. |

## איך זה עובד

```
פוסט שהדבקתם
      ↓
בדיקות בטיחות     עצירת חירום · כפילות · החרגות · תקרה יומית · המתנה לאותו אדם
      ↓
Claude            כוונה, רגישות, מוצר מתאים, ניסוח תגובה והודעת פתיחה
      ↓
חוקי ניסוח        הסרת מחירים, קישורים, טלפונים, אימוג'ים מיותרים
      ↓
הצעה בתור         אתם מאשרים, עורכים או דוחים — וכל אישור מלמד את הטון שלכם
```

**עונתיות:** לכל מוצר אפשר להגדיר חלון תאריכים. מוצר שהעונה שלו מתקרבת או
פעילה מקבל עדיפות בהתאמה, ומוצר שהעונה שלו עברה לא יוצע כלל.

**כל פוסט שנוגע באובדן מסומן אוטומטית כדורש אישור אנושי**, גם כשמצב האוטומציה דלוק.

## הדף העסקי

חיבור חד־פעמי: `python setup_facebook.py` — שואל App ID, App Secret וטוקן קצר,
ועושה את כל השאר לבד (הארכת טוקן, איתור הדף, כתיבה ל-`.env`, אימות).
להביא את שלושת הערכים לפי **[SETUP-FACEBOOK.md](SETUP-FACEBOOK.md)**.

לבדוק חיבור קיים: `python check_facebook.py`

### פרסום מתוזמן

פוסט מאושר עם תאריך מתפרסם כשמריצים:

```bash
python publish_due.py
```

אפשר להריץ ידנית, או לתזמן כל 15 דקות. בלינוקס/מק ב-crontab:

```
*/15 * * * * cd /נתיב/אל/bot && ./venv/bin/python publish_due.py >> data/publish.log 2>&1
```

בווינדוס — Task Scheduler עם אותה פקודה. בלי תזמון, פוסט מאושר פשוט ימתין
עד שתריצו את הפקודה או תלחצו ״פרסם עכשיו״ בממשק.

## מה המערכת לא עושה

**אין גישה תכנותית לקבוצות פייסבוק.** Meta סגרה את ה-Groups API באפריל 2024 —
אין קריאה של פוסטים בקבוצות, אין פרסום בקבוצות, ואין תגובה לפוסטים של אחרים.
אין חלופה רשמית, גם לא לאדמין של הקבוצה. לכן הבוט מנסח ואתם מפרסמים.

מה שכן אפשרי באופן רשמי עם הדף העסקי: פרסום ותזמון בדף, קריאת התגובות על
הפוסטים שלכם, תגובה פומבית, והודעה פרטית אחת לכל מגיב בתוך 7 ימים (דורשת אישור
של Meta). הקוד לזה כתוב ב-`app/facebook.py` וממתין ל-`FB_PAGE_ID`
ו-`FB_PAGE_TOKEN` בקובץ `.env` — ראו **[SETUP-FACEBOOK.md](SETUP-FACEBOOK.md)**.

## פרטיות

`data/bot.db` והתמונות נשארים על המחשב שלכם ומוחרגים מגיט. הטקסטים היחידים
שיוצאים החוצה הם הפוסטים שאתם מדביקים, שנשלחים ל-Claude לצורך הניסוח.
כדאי למחוק פוסטים ישנים מהמסד מדי פעם.

## מה הלאה

1. למלא את זהות העסק במסך ההגדרות.
2. למלא את המוצרים ולהעלות תמונות אמיתיות, ואז לסמן אותם כפעילים.
3. להוסיף 3–5 ניסוחים אמיתיים שכתבתם ללקוחות, במסך ההגדרות — זה מה שגורם לבוט
   להישמע כמוכם ולא כמו בוט.
4. לחבר את הדף (`setup_facebook.py`) ולהתחיל לפרסם.
5. להגיש אימות עסקי ו-App Review כדי לפתוח הודעות בפרטי.
