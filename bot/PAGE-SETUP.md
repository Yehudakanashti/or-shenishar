# עיצוב הדף — מוכן להדבקה

כל מה שצריך למלא בדף **מתנות לכל גיל**. התמונות מוכנות ב-`assets/page/`.

אותן בפועל — כולל הגודל הזעיר שמופיע ליד כל תגובה.

**ההמלצה שלי: האתרוג.** הוא הכי קריא בקטן, כי יש בו צורה אחת בהירה על רקע כהה.
הסוכה יפה אבל הכיתוב עליה נעלם בגודל הזה.

> רוצים לשנות חיתוך, טקסט או צבע? ערכו את `make_page_assets.py` והריצו
> `python make_page_assets.py`. התמונות נוצרות מחדש בשניות.

מוגבל למאה תווים בערך:

```
מוצרי חג מודפסים בתלת־ממד, מוארים מבפנים. הכיתוב — מה שתבחרו.
```

## תיאור מלא (About)

```
אנחנו מדפיסים מוצרי חג בתלת־ממד — סוכות, אתרוגים, רימונים ושלטי ברכה.
כל פריט נבנה שכבה אחר שכבה מחומר בהיר, וכשהאור נדלק מבפנים הכיתוב
והסמלים עולים מתוך החומר.

הכיתוב הוא החלק שלכם: שם, ברכה או משפט אישי — מה שתבחרו, לפי ההזמנה.

לפרטים והזמנות — שלחו הודעה.
```

## כפתור הפעולה

**״שלח הודעה״** — לא ״התקשר״ ולא ״הזמן עכשיו״. כל השיחה נסגרת בפרטי, אז הכפתור
צריך להוביל בדיוק לשם.

## פרטי קשר

למלא **רק** מה שאתם רוצים שיהיה גלוי. הדף עובד מצוין גם בלי טלפון וכתובת,
ואם העסק מהבית — עדיף בלי כתובת.

## חמשת הפוסטים הראשונים

כבר טעונים במערכת כטיוטות עם תמונה ותאריך. להריץ:

```bash
python seed_posts.py
```

ואז לפתוח את מסך **פוסטים**, לעבור עליהם, לערוך ולאשר.

| מתי | על מה |
|---|---|
| 20.9 בערב | נעים להכיר — מי אנחנו ומה אנחנו עושים |
| 21.9 בערב | הסוכה המוארת |
| 22.9 בערב | ההתאמה האישית — דופן האושפיזין ומה אפשר לשים במקום |
| 23.9 בערב | האתרוג |
| 24.9 בבוקר | רגע לפני החג — מי שרוצה כיתוב אישי, שיגיד עכשיו |

**את הפוסט הראשון כדאי להצמיד לראש הדף** (בפייסבוק: שלוש נקודות על הפוסט ←
הצמד לראש הדף). הוא מה שרואים ראשון מי שמגיע מהקבוצות.

## מה לא לעשות

- **לא לקנות לייקים ולא להזמין את כל החברים.** עוקבים שלא מתעניינים הורגים
  את החשיפה של הפוסטים הבאים — פייסבוק מודדת כמה אחוז מהנחשפים הגיבו.
- **לא לפרסם חמישה פוסטים ביום אחד** כדי ״למלא את הדף״. פוסט ביום, בערב.
- **לא לכתוב מחירים בפוסטים** בשלב הזה. מי ששואל — עונים בפרטי.
