## 2. אילוצים קשיחים — אסור להפר

1. **אין API לקבוצות פייסבוק.** Meta סגרה את Groups API ב-22.4.2024, הסירה
   את `publish_to_groups` ו-`groups_access_member_info`, ואין חלופה — גם לא
   לאדמין של הקבוצה. אל תנסה לבנות אינטגרציה לקבוצות, ואל תציע אוטומציית
   דפדפן על החשבון האישי: זה מנוגד לתנאי השימוש ומסכן את החשבון. הזרימה
   בקבוצות היא: הבוט מנסח, הבעלים מעתיק ומפרסם.
2. **אף פעם לא מחיר בתגובה ציבורית.** הכלל נאכף בקוד (`policy.check_comment`)
   ולא רק בפרומפט. אל תחליש אותו.
3. **פוסט שנוגע באובדן ← `needs_human=True` תמיד**, גם כשמצב האוטומציה דלוק.
   נאכף ב-`engine.ingest`.
4. **שדה `avoid` של כל מוצר הוא הוראה קשיחה.** כרגע מכיל: סוג התאורה, מקור
   הכוח ומשך הדליקה; זמני אספקה ומשלוח; מחיר בתגובה. הבעלים ביקש מפורשות
   לא לחשוף את אלה.
5. **לא מפרסמים בשבת ובחג.** `app/timing.py` חוסם משישי 15:00 עד מוצאי שבת
   20:30, ובנוסף תאריכים שמוגדרים בהגדרות. `publish_due` מכבד את זה.
6. **AUTO OFF היא ברירת המחדל.** שום תגובה ושום פוסט לא יוצאים בלי אישור
   מפורש של הבעלים בממשק.

## 4. מה בנוי ועובד

### מנוע התגובות (הליבה)

```
פוסט שהודבק
      ↓
safety.check      עצירת חירום · כפילות · החרגות · תקרה יומית · המתנה לאותו אדם
      ↓
ai.analyze        Claude עם פלט מובנה: כוונה, רגישות, מוצר, תגובה, הודעת פתיחה
      ↓
matching          אימות בחירת המוצר לפי מילות מפתח ועונה
      ↓
policy            הסרת מחירים, קישורים, טלפונים, אימוג'ים מיותרים
      ↓
הצעה בתור        אישור / עריכה / דחייה — וכל אישור נשמר כדוגמת טון
```

### מפת הקוד

| קובץ | תפקיד |
|---|---|
| `app/config.py` | הגדרות, מפתחות מ-`.env`, ברירות מחדל |
| `app/db.py` | SQLite: מוצרים, תמונות, פוסטים, הצעות, דוגמאות, החרגות, יומן |
| `app/schema.sql` | מבנה הטבלאות. מיגרציות ב-`db.MIGRATIONS` |
| `app/safety.py` | בולמי הנזק לפני יצירת הצעה |
| `app/ai.py` | `analyze()` לתגובות, `draft_post()` לפוסטים. Pydantic + `messages.parse` |
| `app/matching.py` | ניקוד מוצרים לפי מילות מפתח + מצב העונה |
| `app/policy.py` | `check_comment` · `check_post` · `check_dm` |
| `app/timing.py` | חסימת שבת, חגים וזמנים שהוגדרו |
| `app/engine.py` | חיבור הכול לזרימה אחת |
| `app/publisher.py` | ניסוח, פרסום ותזמון פוסטים לדף |
| `app/facebook.py` | Graph API: פרסום, תגובות, הודעה פרטית, עריכת פרטי הדף |
| `app/web.py` | Flask — הדשבורד |

## 5. מה חסר — לפי סדר עדיפויות

### משימה 1 · מפתח Claude ⛔ חוסם הכול

בלעדיו `ai.analyze` ו-`ai.draft_post` נופלים לנוסח תבניתי חלש.

```cmd
echo %ANTHROPIC_API_KEY%
```

אם ריק — ליצור ב-console.anthropic.com (Settings ← API Keys), ולכתוב ל-`bot\.env`:
`ANTHROPIC_API_KEY=sk-ant-api...`

**בדיקת קבלה:** להריץ `python run.py`, להדביק פוסט אמיתי בתור האישורים,
ולוודא ש-`engine` בוחר מוצר נכון ושהניסוח לא תבניתי. במסך ההצעה יופיע שם
המודל במקום `template`.

### משימה 2 · חיבור הדף ⛔ חוסם את כל החלק של הדף

הבעלים צריך ליצור אפליקציה ב-developers.facebook.com (סוג Business), ולהפיק
טוקן משתמש קצר ב-Graph API Explorer עם חמש ההרשאות:

```
pages_show_list  pages_read_engagement  pages_manage_posts
pages_manage_engagement  pages_manage_metadata
```

ואז `python setup_facebook.py` — הוא מאריך את הטוקן, מאתר את הדף, כותב
ל-`.env` ומאמת. הפירוט המלא ב-`SETUP-FACEBOOK.md`.

**בדיקת קבלה:** `python check_facebook.py` מדפיס את שם הדף ומספר העוקבים.

> **אזהרה:** `setup_facebook.py`, `check_facebook.py` ו-`setup_page.py` נכתבו
> מול התיעוד ולא נבדקו מול API אמיתי. צפה לתקן פרטים בקריאה הראשונה —
> במיוחד את העלאת תמונת הפרופיל (`POST /{page-id}/picture`) ואת תמונת
> הכיסוי (העלאה לא מפורסמת ואז `POST /{page-id}` עם `cover=<photo_id>`).
> אם Meta החזירה שגיאה, קרא את ההודעה המלאה לפני שאתה משנה גישה.

### משימה 3 · דוגמאות טון מהבעלים

3–5 תגובות או הודעות אמיתיות שהבעלים כתב ללקוחות בעבר. נכנסות דרך
**הגדרות ← דוגמאות טון**, ומוזנות אוטומטית לפרומפט כ-few-shot.

זה השיפור הגדול ביותר באיכות הניסוחים, והוא לא דורש שורת קוד — רק לבקש
מהבעלים ולהזין.

### משימה 4 · השלמת פרטי המוצרים

חסרים בכל ארבעת המוצרים, ומסומנים בשדה ההערות:

- **מחיר** — לשיחה בפרטי בלבד
- **מידות** — הבעלים אמר שהן בשיחה אחרת שלו; לבקש ממנו שורה לכל מוצר

נכנס דרך **מוצרים ← עריכה**.

### משימה 5 · עיצוב הדף

אחרי משימה 2:

```cmd
python setup_page.py          :: תצוגה בלבד — מה קיים ומה ישתנה
python setup_page.py --apply  :: ביצוע
```

הטקסטים והתמונות כבר מוכנים. הבעלים בחר להמשיך משם בהוראות חופשיות
(״תשנה את התיאור ל…״) — כלומר צפה לערוך את הקבועים ב-`setup_page.py`
ולהריץ שוב.

**עוד לא נעשה ודורש את הבעלים:** שם משתמש לדף, קטגוריה, וכפתור ״שלח הודעה״.
שלושתם נקבעים בממשק של פייסבוק, לא ב-API. ההמלצות ב-`PAGE-SETUP.md`.

### משימה 6 · פוסטי הפתיחה

חמש טיוטות מוכנות (`python seed_posts.py`). **הבעלים ביקש לא להתחיל מפוסטים**
עד שהדף יחובר — אל תפרסם לפני שהוא אישר.

### משימה 7 · הודעות בפרטי (ימים עד שבועות)

`pages_messaging` דורשת אימות עסקי (מסמכי ח.פ) ו-App Review מול Meta.
הקוד מוכן (`facebook.private_reply`). עד שזה עובר, הבוט יכול לשלוח בפרטי
רק לחשבונות עם תפקיד באפליקציה.

**מגבלה שאסור לשכוח:** הודעה פרטית אחת בלבד לכל מגיב, בתוך 7 ימים מהתגובה.
אין הזדמנות שנייה.

### משימה 8 · תזמון אוטומטי

כרגע `publish_due.py` רץ ידנית. להגדיר Task Scheduler בווינדוס שיריץ אותו
כל 15 דקות:

```cmd
cd C:\Users\hod45\or-shenishar\bot && venv\Scripts\python.exe publish_due.py
```

### משימה 9 · מוצרי חנוכה

קיימים פיזית, אין עליהם תמונות ומידע. חנוכה: 4–12.12.2026. לבקש מהבעלים
תמונות ופרטים, ולהוסיף כמוצרים עם `occasion=חנוכה` וחלון עונה מתאים.

## 8. סגנון הקוד

- עברית בכל מה שהמשתמש רואה: ממשק, הודעות שגיאה, פלט סקריפטים, הערות.
- הערות מסבירות **למה**, לא **מה**.
- כל כלל עסקי נאכף בקוד ולא רק בפרומפט — המודל יכול לטעות.
- כישלון מחזיר הודעה בעברית שמסבירה מה לעשות, לא traceback.
- אין תלויות חדשות בלי סיבה טובה. כרגע: Flask, anthropic, python-dotenv,
  ו-Pillow רק לייצור תמונות הדף.
